# 技術と見た目の方針（v1）

## 1. 技術

| 項目 | 選んだもの | 理由 |
|---|---|---|
| 遊ぶ場所 | ブラウザ（PC・スマホ） | インストールなしで遊べる。のちにアプリにもできる |
| 言語 | TypeScript | 型があるので、大きくなっても壊れにくい |
| ゲームエンジン | Phaser 3 | 2Dの横スクロールに向いている。当たり判定・アニメーション・タイルマップ・音がそろっている |
| ビルド | Vite | 起動と更新が速い |
| マップ編集 | Tiled（無料のマップエディタ） | Phaser がそのまま読み込める。部屋・敵・宝箱の配置をJSONで保存できる |
| テスト | Vitest（計算や保存の処理）／Playwright（起動して動くかの確認） | |
| セーブ | localStorage | |

### 物理
Phaser の Arcade Physics を使う。坂は使わず、四角いタイルだけにして、当たり判定を単純に保つ。
主人公の動き（コヨーテタイム、先行入力、落ちるときの重力など）は自分で書く。

## 2. フォルダ構成（予定）

```
src/
  main.ts            … ゲームの起動
  config.ts          … 数値の設定（docs/03 の値をここに集める）
  scenes/            … タイトル、ゲーム、HUD、メニュー、会話
  entities/          … 主人公、敵、ボス、弾、宝箱、扉
  systems/           … 入力、戦闘、成長、セーブ、部屋の移動、会話
  data/              … 装備・敵・会話の表（JSON）
public/assets/
  maps/              … Tiled のマップ
  sprites/ tiles/ audio/
tests/
```

## 3. 見た目

- **ドット絵**。キャラクターは 16×24px くらい、タイルは 16×16px。
  - 原作は3Dだが、少人数でも作りやすく、雰囲気を出しやすいドット絵にする。
- 画面は 480×270px。整数倍で拡大してくっきり表示する。
- **光と影がテーマ**なので、次の2つに力を入れる。
  1. 背景を奥から3〜4枚重ねて、横にずらしながら動かす（視差スクロール）
  2. 灯・魔法・宝箱のまわりを光らせる（加算合成と、暗い場所だけのライティング）
- エリアごとの色：
  | エリア | 色 |
  |---|---|
  | ハルナ村 | 夕焼けのオレンジ・木の茶色 |
  | ささやきの森 | 深い緑・ホタルの黄緑 |
  | 石の心臓 | 灰色・ランプの橙 |
  | 天の祠 | 空色・白 |
  | アクアリア | 青緑・光る苔 |
  | 竜の炉 | 赤・黒 |
  | 虚の塔 | 白黒（灯だけ色がつく） |

- **最初は四角や簡単な図形で仮の絵を作り**、遊びが固まってから絵を描き直す。

## 4. 音
- 最初は無料素材か、効果音作成ツール（jsfxr など）で作った音を使う。
- エリアごとに曲を1つ、ボス戦に1つ、ラスボスに1つ。

## 5. 作る順番

| 段階 | 内容 | 終わりの目安 |
|---|---|---|
| 1 | 土台づくり（Vite + Phaser + TypeScript） | 画面に四角い主人公が出る |
| 2 | 主人公の動き | 走る・跳ぶ・二段ジャンプが気持ちいい |
| 3 | 剣と敵 | 3段斬り・打ち返し・影スライムを倒せる |
| 4 | 部屋の移動と Tiled のマップ | 森の3部屋を行き来できる |
| 5 | HUD・経験値・灯貨・壺と草 | レベルアップで3択が出る |
| 6 | 会話・灯の泉・セーブ | 村で話せて、セーブと再開ができる |
| 7 | ボス（影喰い狼） | **プロローグを最初から最後まで遊べる** ← 最初の目標 |
| 8 | 第1章 | 二段ジャンプで前のエリアに戻れる |
