# 実装メモ（本編 v1）

本編（プロローグ〜第6章・エンディング）とグラフィックを実装した時点の記録。
設計資料（02〜05）から変えたところは「設計からの変更点」にまとめる。

## 1. グラフィック

画像ファイルは使わず、起動時にコードでドット絵を描いている（`src/art/`）。

| 種類 | 作り方 |
|---|---|
| 人物 | 骨組み（リグ）で手足と剣の角度を決めて描く。リオ・NPC・騎士・ノクスは同じ仕組み（`humanoid.ts`） |
| 敵・ボス | 図形の組み合わせで描く（`creatures.ts` / `enemies.ts`） |
| 地形 | エリアごとの色と質感で16種類のつなぎ目を自動生成（`tiles.ts`） |
| 背景 | 空・遠景・中景の3枚を重ねて、視差スクロール（`backgrounds.ts`） |
| 小物 | 家・木・風車・水晶・祭壇など約40種（`props.ts`） |
| 演出 | 暗い部屋の明かり、剣の軌跡、パーティクル（蛍・火の粉・泡など） |

`npm run dev` の後に `http://localhost:5173/art.html` を開くと、全部の絵を一覧できる（開発用）。

## 3. 仕組み

- **部屋のつながり**：地図の数字（0〜9）で部屋同士を結ぶ。端にあれば歩いて移動、中にあれば扉（↑で入る）。
- **鍵**：小さな鍵はそのエリアの鍵付き扉に使う。ボスの鍵はボス扉を開ける。
- **灯台**：一度点けると、点けた灯台どうしでワープできる。
- **お店**：村・ドルム・アクアリア・竜の炉。
- **仕掛け**：灯の玉と門、水位の切り替え、上昇気流、崩れる足場、ひびの壁、光の格子、上がってくる溶岩。
- **サブクエスト（託された灯）**：12個すべて実装。数によってルミナブレードの効果とエンディングが変わる。
  - 4個以上：溜め斬りで光の波
  - 8個以上：HPが少しずつ回復
  - 12個：最終決戦でミナとカイが助けてくれる、特別なエンディング
- **メニュー**（Esc / Tab）：装備、持ち物、ステータス、記録。やさしいモードの切り替えもここ。
