# マップ設計（v1）

> 1部屋 = 1画面以上（最小 30×17タイル）。横や縦に長い部屋もある。
> 部屋同士は画面の端でつながる。扉に入ると別の部屋へ移動する。

---

## 1. 世界全体のつながり

```
                       [天の祠] ★2
                          │（二段ジャンプが必要）
                     [風の高原]───────────[王都ルミエ]──[虚の塔] ★6
                          │                    │（第6章で出現）
 [ささやきの森]──[ハルナ村]──[街道]──[鉱山町ドルム]──[石の心臓] ★1
       │序            │                  │
       │         （灯爆で開く）        （灯弾で開く）
   [影の回廊]      [村の地下]           [地底湖]
   （クリア後）                           │
                                   [沈んだ都アクアリア] ★3
                                          │（灯爆で開く）
                                     [竜の炉] ★4
★ = 剣の欠片やラスボスがあるダンジョン
```

### 進む順番と「力の鍵」
| 行き先 | 必要な力 | 手に入る場所 |
|---|---|---|
| 鉱山町ドルム | なし | ― |
| 風の高原 → 天の祠 | 二段ジャンプ | 石の心臓（第1章） |
| 地底湖 | 灯弾（入口の灯の玉を点ける） | 天の祠（第2章） |
| アクアリアの奥 | 灯渡り | アクアリア（第3章の中盤） |
| 竜の炉 | 灯爆（入口の岩を壊す） | 第3章の終わりにミナから教わる |
| 虚の塔 | ルミナブレード | 第5章 |
| 虚の塔の霧の階 | 灯守り | 竜の炉（第4章） |

## 2. エリアの詳細

### 序章 ハルナ村
- **雰囲気**：山あいの小さな村。夕焼け、風車、木の家。
- **部屋の数**：5（村の広場、長老の家、店、鍛冶屋、村の地下（クリア後））
- **施設**：灯の泉、灯台、店（灯の雫・革のベスト・磁石の石）、鍛冶屋（サブクエスト2）
- **あとで戻る理由**：村の地下（灯爆で開く）→ 灯の器と「影の回廊」の入口

### 序章 ささやきの森
- **雰囲気**：背の高い木と、ホタルの光。奥に行くほど暗くなる。
- **部屋の数**：8
- **敵**：影スライム、影コウモリ、虚の狼（小）
- **チュートリアルの順番**：
  1. 歩く・ジャンプ（倒れた木を越える）
  2. 剣（草を斬る、壺を割る）
  3. 敵（影スライム1匹）
  4. 落ちると戻される穴（ダメージ1）
  5. 3段斬り（虚の狼）
  6. 弾の打ち返し（木の上のコウモリが投げる実）
  7. ボス：影喰い狼
- **隠し要素**：灯の器1つ（二段ジャンプで届く高い木の上）

### 第1章 鉱山町ドルム
- **雰囲気**：崖にへばりついた町。ランプ、トロッコ、煙。
- **部屋の数**：6
- **施設**：灯の泉、灯台、店（鉱夫の鉈・鉱夫の胸当て）、ミナの地図屋（ここが初登場）
- **サブクエスト**：3、4

### 第1章 石の心臓（ダンジョン）
- **部屋の数**：14
- **仕掛け**：
  - トロッコに乗って進む（ジャンプで障害物を避ける）
  - 暗い坑道（ランプを剣で叩いて点ける）
  - 動く足場と落ちてくる岩
  - 小さな鍵2つ → ボスの鍵
- **中ボス**：岩虫の女王（二段ジャンプのブーツを守っている）
- **二段ジャンプを取ったあと**：入口近くの高い場所に戻ると、宝箱の近道がある
- **ボス**：岩喰いゴーレム

### 第2章 風の高原
- **雰囲気**：広い草原、止まった風車、空に浮かぶ岩。
- **部屋の数**：10（横に長い部屋が多い）
- **仕掛け**：風で押される場所、風に乗って高く跳ぶ場所
- **サブクエスト**：5、6
- **カイと初めて会う**：高原の真ん中で虚の群れと一緒に戦う

### 第2章 天の祠（ダンジョン）
- **部屋の数**：16（縦に長い塔）
- **仕掛け**：
  - 灯弾で離れた灯の玉を点けると、足場が出る
  - 鏡で灯弾を反射させる
  - 打ち返しでしか届かないスイッチ
  - 鏡の部屋（リオの影が一瞬遅れて動く演出 → 伏線）
- **ボス**：大鷲テンペスト（塔の屋上）

### 第3章 地底湖
- **部屋の数**：6
- ドルムの奥とつながる。光る苔、静かな水。泳ぐことはできず、足場を渡っていく。

### 第3章 沈んだ都アクアリア（ダンジョン）
- **部屋の数**：20（一番大きなダンジョン）
- **仕掛け**：
  - 水位スイッチ：水を上げ下げすると、行ける場所が変わる
  - 光の格子：灯渡りですり抜ける
  - 壁画：物語の真実が少しずつ分かる（学者のサブクエストの石版）
- **中ボス**：沈んだ騎士長（パリィを教わるカイとの勝負はこの直前）
- **ボス**：深き者レヴィア

### 第4章 竜の炉（ダンジョン）
- **部屋の数**：15
- **仕掛け**：
  - 溶岩が上がってくる縦の部屋（急いで登る）
  - 灯爆で岩を落として溶岩の流れを変える
  - 冷えた溶岩の足場は、しばらくすると崩れる
- **ボス**：溶岩竜イグニア → カイ

### 第5章 ハルナ村（夜）
- 戦いなし。村人全員と話せる。託された灯を集める場面。
- 竜の炉へワープして剣を打ち直す（イベント）。

### 第6章 王都ルミエ／虚の塔
- **王都**（部屋の数 6）：灯を吸われて人が止まっている街。黒と白だけの色になっている。
- **虚の塔**（部屋の数 18）：これまでのダンジョンの仕掛けが全部出てくる、まとめの塔。
  - 1〜3階：石の心臓風、4〜6階：天の祠風、7〜9階：アクアリア風、10〜12階：竜の炉風
  - 屋上：ノクス戦
- 塔の中にも灯の泉が3つある。

### クリア後 影の回廊
- 強い敵が出る10部屋と、ボスの強化版との連戦。
- ごほうび：欲張りの指輪、隠しエンディングの絵。

## 4. 部屋を作るときのルール

1. **新しい仕掛けは「安全な場所で見せる → 簡単に使う → 組み合わせる」の順番**で出す。
2. 行けない場所は、**入口を見せておく**（「あとで戻ってこよう」と思わせる）。
3. 灯の泉からボス部屋までは1〜2部屋にする（負けてもすぐ再挑戦できる）。
4. 1つのダンジョンを通しで遊んで15〜25分に収める。
5. 行き止まりには、必ず何か（宝箱、壺、景色）を置く。
