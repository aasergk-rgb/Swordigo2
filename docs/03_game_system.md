# ゲームシステム設計（v1）

> 数値はすべて仮の値。試作で遊びながら調整する。
> 単位：1タイル = 16px、画面 = 480×270px（整数倍で拡大表示）、60fps。

---

## 1. 操作

| 行動 | キーボード | ゲームパッド | タッチ |
|---|---|---|---|
| 移動 | ← → | 左スティック / 十字キー | 左下の十字パッド |
| 上を向く／扉に入る／話す | ↑ | 上 | 十字パッドの上 |
| しゃがむ／下突き（空中） | ↓ | 下 | 十字パッドの下 |
| ジャンプ | Z / Space | A | 右下のボタン |
| 剣 | X | X | 右下のボタン |
| 魔法 | C | Y | 右下のボタン |
| 魔法の切り替え | A / S | LB / RB | 魔法ボタンを長押しして選ぶ |
| 回復薬 | Q | B | 画面上のアイコン |
| マップ／メニュー | Tab / Esc | Select / Start | 右上のアイコン |

- ダッシュは専用ボタンにせず、**移動キーの2回押し**で出す（原作と同じ）。ゲームパッドはスティックを倒し切るとダッシュになる。
- すべてのキーは設定画面で変えられるようにする。

## 2. 主人公の動き

| 項目 | 値 | メモ |
|---|---|---|
| 歩く速さ | 90 px/秒 | |
| ダッシュの速さ | 150 px/秒 | 2回押しの受付は0.25秒 |
| 加速／減速 | 0.08秒で最高速／0.05秒で停止 | きびきび動かす |
| ジャンプの高さ | 3.5タイル（56px） | ボタンを早く離すと低く跳ぶ（最低1.5タイル） |
| 二段ジャンプ | 2.5タイル | 第1章で手に入る |
| 重力 | 900 px/秒² | 落ちるときは1.4倍（ふわっとさせない） |
| 最高落下速度 | 300 px/秒 | |
| コヨーテタイム | 0.1秒 | 足場から落ちた直後でもジャンプできる |

## 3. 剣

### 3.1 基本の攻撃
| 技 | 入力 | 威力 | 出るまで／硬直 | 内容 |
|---|---|---|---|---|
| 1段目 | 剣 | 攻撃力 ×1.0 | 0.05秒／0.20秒 | 横に振る |
| 2段目 | 1段目の後に剣 | ×1.0 | 0.05秒／0.20秒 | 返し斬り |
| 3段目 | 2段目の後に剣 | ×1.6 | 0.10秒／0.35秒 | 突き。敵を大きく吹き飛ばす |
| 上斬り | ↑ + 剣 | ×1.0 | 0.06秒／0.25秒 | 真上を斬る。飛んでいる敵に使う |
| 下突き | 空中で ↓ + 剣 | ×1.2 | すぐ出る | 当たると**跳ね返って少し浮く**。トゲの上も渡れる |
| 空中斬り | 空中で剣 | ×1.0 | 0.05秒／0.20秒 | 空中では2段まで |

- コンボは、前の攻撃から0.35秒以内に押すとつながる。
- 攻撃が当たると0.04秒だけ画面を止めて（ヒットストップ）、手ごたえを出す。

### 3.2 剣でしかできないこと
| 技 | 手に入る時期 | 内容 |
|---|---|---|
| **打ち返し** | 最初から | 敵の弾を斬ると、その弾が敵に向かって飛ぶ。威力は2倍。スイッチの謎解きにも使う |
| **溜め斬り** | 第2章（ガレンの教え） | 剣ボタンを1秒押し続けて離す。攻撃力×3、敵の盾を壊す |
| **パリィ** | 第3章（カイとの勝負） | 敵の攻撃が当たる直前0.12秒以内に剣を振ると、はじいて敵をひるませる。成功すると魔力が5回復する |

魔法ばかり使うと魔力がすぐ足りなくなり、剣で戦うと魔力が戻る。こうして**剣と魔法を交互に使う流れ**を作る。

## 4. 魔法

- 魔力（MP）を使う。最初の上限は20。
- **剣で敵に当てると1回復**。灯の泉（セーブ地点）で全回復する。

| 魔法 | 手に入る時期 | MP | 威力 | 内容 | 探索での使い方 |
|---|---|---|---|---|---|
| **灯弾（ともしびだん）** | 第2章 | 3 | 魔力 ×1.0 | まっすぐ飛ぶ光の弾 | 離れたスイッチ（灯の玉）を点ける |
| **灯渡り（ともしびわたり）** | 第3章 | 5 | ― | 前方4タイルに瞬間移動。移動中は無敵 | 光の格子や細い壁を抜ける |
| **灯爆（ともしびばく）** | 第3章の終わり（ミナから） | 8 | 魔力 ×2.5（範囲） | 置いて1.2秒後に爆発する | ひびの入った壁・床を壊す |
| **灯守り（ともしびもり）** | 第4章 | 12 | ― | 3秒間、光の盾で守る。当たった弾は打ち返す | 虚の霧の中を進む |

- 各魔法はお店の「魔導書」で2回まで強くできる（威力や距離が上がり、MPが下がる）。

## 5. 成長

### 5.1 レベルアップ
- 敵を倒すと経験値（EXP）が入る。
- 次のレベルに必要なEXP：`floor(20 × レベル^1.5)`
  - 例：Lv1→2 は 20、Lv5→6 は 223、Lv10→11 は 632。
- 最高レベルは30。クリアまでにLv18〜20くらいになる想定。
- レベルが上がると、**次の3つから1つを選ぶ**（原作と同じ）。

| 選んだもの | 上がる量 | 初期値 |
|---|---|---|
| 体力 | 最大HP +2 | 10 |
| 攻撃力 | 剣の基本威力 +1 | 3 |
| 魔力 | 最大MP +4、魔法威力 +1 | MP 20／魔法威力 3 |

- レベルアップするとHPとMPは全回復する。
- 村の「灯の祭壇」に灯貨を払うと、振り直しができる（クリア後は無料）。

### 5.2 HPの器
- 各エリアに1〜2個隠してある「灯の器」を取ると、最大HPが+2される（全8個）。

## 8. お金（灯貨）と死んだとき

- 敵、壺、宝箱から手に入る。
- **死んだとき**：最後に触った灯の泉から再スタートする。持っている灯貨の**10%を失う**。経験値とアイテムは失わない。
  - 原作と同じように、やさしめの難しさにする。
- 灯の泉：HPとMPを全回復し、セーブする。灯の灯台（ワープ）とは別。

---

## 9. ワープとセーブ

- **灯の灯台**：各エリアに2〜3か所ある。一度点けると、どの灯台からでもワープできる。
- **灯の泉**：セーブ地点。ボス部屋の前には必ず置く。
- セーブデータは3つ。ブラウザの localStorage に保存する（のちにクラウド保存も検討）。
- 保存する内容：位置、レベル・能力、装備、持ち物、手に入れた力、開けた宝箱・扉・スイッチ、倒したボス、サブクエストの進み具合、遊んだ時間。

## 13. 難しさの目安

- 原作と同じくらいか、少しやさしめ（ボス戦だけ少し歯ごたえがある）。
- 「やさしいモード」を選べる：受けるダメージ半分、死んでも灯貨を失わない。
- クリアまで8〜10時間。全部集めて12〜14時間。
