# Swordigo 調査メモ

新作づくりの参考にするため、原作 *Swordigo* を調べた内容をまとめる。

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 開発・販売 | Touch Foo（フィンランドのインディースタジオ） |
| 発売日 | 2012年3月22日 |
| 対応機種 | iOS / Android |
| ジャンル | 横スクロールのアクションアドベンチャー（RPG要素あり） |
| 評価 | Metacritic 86/100。TouchArcade 4.5/5、AppSpy 5/5 |
| 影響元 | 『ゼルダの伝説 リンクの冒険』『メトロイド』『悪魔城ドラキュラ』 |
| プレイ時間 | 約10時間 |

見た目は3Dモデルだが、遊びは2Dの横スクロール（いわゆる2.5D）。

## 2. ストーリー（原作）

1. 名前のない若者が、師匠が死ぬ夢を見て目を覚ます。
2. 森へ探しに行くと、師匠は本当に死んでいた。遺されたメモには **Corruptor（コラプター）** という闇の怪物のことが書かれていた。
3. 主人公もコラプターに襲われて気を失う。
4. 村の長老（The Elder）の頼みで、コラプターを倒せる唯一の剣 **Mageblade（メイジブレード）** を探す旅に出る。
5. 剣はコラプターに4つに割られていた。各地のダンジョンで欠片を集める。師匠の幽霊が道を教えてくれる。
6. 最後に、主人公と同じ姿をしたコラプターの王 **Master of Chaos（混沌の主）** と戦う。
7. 勝ったあと、主人公は王の近衛兵になる。

**よくできている点**：「師匠の死 → 伝説の剣 → 欠片集め → 自分の影との対決」という分かりやすい流れで、プレイヤーの目的がいつもはっきりしている。

**弱い点**：主人公に名前も性格もなく、ほかのキャラクターの掘り下げも少ない。「なぜ自分の姿の敵なのか」がほとんど説明されない。

## 3. ゲームシステム

### 3.1 操作
- 左右移動、ジャンプ、剣、魔法の4ボタン（タッチ操作）
- 移動キーを素早く2回押すとダッシュ。空中でジャンプを押すと二段ジャンプ（入手後）
- 剣で敵の弾を打ち返せる（「野球のように」と紹介されている）

### 3.2 魔法（4種）
| 魔法 | 効果 |
|---|---|
| Magic Bolt | まっすぐ飛ぶ魔法弾。オーブを撃ってスイッチを入れることもできる |
| Magic Bomb | 設置型の爆弾。壊せる壁や敵に使う |
| Dragon's Grasp | 炎の攻撃魔法 |
| Dimension Rift | 短い距離をワープ。魔法の扉や障害物を通り抜ける |

魔法を覚えると新しいルートが開く、メトロイドヴァニア型の作り。

### 3.3 成長と装備
- 敵を倒すと経験値。**レベルアップのたびに「体力・攻撃力・魔力」のどれか1つを上げる**
- 通貨は **Soul Shards（ソウルシャード）**。店で武器・防具・アクセサリー・回復薬を買う
- 剣は初期の剣 → The Needle → The Thorn → Mageblade と強くなる
- 防具とアクセサリーで能力が上がる
- 宝箱からは経験値袋やお金が出る。壺を割ったり草を切ったりしても回復アイテムやお金が出る

### 3.4 探索
- 森、洞窟、神殿、街など11以上のエリアがつながった1枚のマップ
- ワープポータルで移動済みの場所へ戻れる。マップ画面あり
- 鍵・扉、箱を積む、オーブを叩く、魔法の門などの謎解き
- 隠し宝箱を探すやりこみ要素

### 3.5 主な敵・ボス
- 雑魚：スライム系、コウモリ、ゴブリン系、メイジ（魔法使い）、コラプター
- ボス：Krymil、Boulder（岩の巨人）、Magmatar（溶岩の怪物）、Magus（フロレンナムのダンジョン入口を守る魔術師）、Master of Chaos（ラスボス）
- 主な地名：Outskirts of Florennum、Dungeon of Florennum、Wastelands など

## 4. 評判から分かったこと

| 良い点（残す） | 悪い点（直す） |
|---|---|
| 操作の反応がよく、ジャンプが気持ちいい | 剣の攻撃が単調で、コンボがない |
| 探索して能力を得て戻る楽しさ | 剣を振っている間はほとんど動けない |
| 分かりやすい成長（3つから1つを選ぶ） | 魔法の方が剣より強く、剣を使う理由が薄い |
| 雰囲気のある景色と音楽 | ストーリーとキャラクターが薄い |
| 10時間ほどでちょうどよく終わる | 独自性が少ない |

## 5. 新作に活かす方針

1. **残すもの**：横スクロール探索、魔法で道が開く作り、3択のレベルアップ、ソウル型の通貨、ワープポータル、弾を打ち返す剣
2. **直すもの**：
   - 剣にコンボ・溜め斬り・上下への攻撃を入れ、剣でしかできないことを作る
   - 主人公に名前・目的・性格をつけ、仲間やライバルを置く
   - 「自分の影との対決」にしっかりした理由（伏線）を用意する
3. **オリジナルにするもの**：世界観・名前・敵・剣の設定はすべて新しく作る（原作の固有名詞は使わない）
